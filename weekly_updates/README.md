# Weekly updates (8 required)

Each file follows the mandatory format from the mini-project guidelines. **Replace every
`[FILL]` token with real evidence before submission** — paths to code/notebooks/figures,
actual metrics, and the name of the member who did each task. Do not fabricate results;
these templates document the work that the repository actually contains.

Required sections in every update: Week/Date, Work Completed, Evidence, Experiments &
Results, Problems/Failure Analysis, Technical Decisions, References Used This Week,
Individual Contributions, Next Week Plan.
